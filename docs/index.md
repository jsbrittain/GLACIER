# GLACIER

**G**raphical **L**aunchpad for **A**nalysis, **C**omputation, **I**nference and **E**xplication of **R**esults

GLACIER is a desktop application for orchestrating bioinformatics workflows. It provides a graphical interface for discovering, installing, configuring, running, and monitoring computational pipelines powered by Nextflow and Docker.
